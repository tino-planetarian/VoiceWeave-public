# VoiceWeave

Windows用の日本語音声入力ツールです。ショートカットキーを押して話し、もう一度押すと、話した言葉が今カーソルのある場所に入力されます。音声の認識はこのPCの中で行います（設定でクラウドも選べます）。

**📖 [画像つきの使い方マニュアルはこちら](https://tino-planetarian.github.io/VoiceWeave-public/)**

> 個人が趣味と学習を兼ねて、AIと一緒に作っている試用版です。作者自身がふだん使いながら改良しています。すべてのPCで確かめられているわけではありませんが、文章入力が少しでも楽になれば幸いです。気づいたことがあれば、ぜひ教えてください。

## できること

| ショートカット | 動き |
| --- | --- |
| **F8** | 録音の開始・停止。話した言葉に忠実に書き起こして入力します |
| **F9** | 整形モード。話した内容を、メールなどに使える文章に整えてから入力します（AIの設定が必要） |
| **Shift+F9** | 作文モード。「〇〇さんに、来週の打ち合わせの日程を確認するメールを」のような依頼から文章を作ります |
| **Shift+F8** | 英語で話すとき（設定でオンにすると使えます） |
| **Ctrl+Alt+V** | 直前の結果をもう一度入力 |
| **Esc** | 録音中に押すと、録音を取り消します |

ショートカットは設定画面で変えられます。

- 言いよどみ（「えーと」など）の除去、言い直しの整理（「3時、いや4時」→「4時」）、漢数字の整え（「三十分」→「30分」）を自動で行います。
- 自分の言葉を辞書や用語集に登録すると、固有名詞を正しく書きやすくなります。
- 入力先のウィンドウが録音中に変わったときは、勝手に入力せず、クリップボードへコピーだけします。画面をロックしたときも同じです。

## 動作環境

- Windows 10 / 11（64ビット）
- ディスクの空き: アプリと認識モデルで約3GB
- メモリ: 8GB以上（16GB以上をおすすめ）
- NVIDIAのGPUがあると速くなります（なくても動きます）
- マイク

## インストール

1. [Releases](../../releases) から `VoiceWeave_x.y.z_x64-setup.exe` をダウンロードします。
2. 実行すると、Windowsの「WindowsによってPCが保護されました」という青い画面が出ることがあります。電子署名をしていないためです。「詳細情報」→「実行」で進めてください。
3. インストール後、VoiceWeaveはタスクトレイ（画面右下）に常駐します。アイコンを右クリック→「設定を開く」で設定画面が開きます。

新しい版に更新するときは、VoiceWeaveをトレイから終了してから、新しいインストーラーをそのまま実行します。設定・辞書・認識モデルは残ります。

## 初めて使うとき

1. 設定画面の「初期設定」タブで、**認識モデル**を導入します（標準モデル、約1.6GB、ダウンロードに数分）。
2. NVIDIAのGPUがあるPCは、同じタブの「GPU高速化を導入する」で速くなります。
3. 表示が「利用可能」になったら、メモ帳などを開いて **F8** を押し、話して、もう一度 **F8** を押します。

### 認識エンジンの選び方（「初期設定」タブ）

- **Whisper 標準（turbo）**: ふだんはこれ。GPUがあると速い。
- **Whisper 高精度（large-v3）**: より正確ですが遅く、メモリも多く使います。
- **Parakeet 日本語**: CPUだけでも速い。GPUがないPC向け。
- **クラウド（Groq）**: 声を米国のGroq社に送って認識します。とても速く正確ですが、GroqのAPIキーが必要です（無料枠あり）。

## 整形モード・作文モード（F9・Shift+F9）

「整形」タブで、文章を整えるAIを選びます。

- **このPC内のAI**: 無料で、文章はPCの外に出ません。[Ollama](https://ollama.com/) が必要です（設定画面からインストールできます）。
- **OpenAI / Anthropic**: 外部のAIです。各社のAPIキーが必要で、使った分だけ料金がかかります（1回あたり0.1円程度）。

APIキーはWindowsの資格情報マネージャーに保存され、ファイルには残りません。

## 辞書と用語集

- **辞書**: 「クロード → Claude」のように、聞き違いやすい言葉の正しい書き方を登録します。
- **分野の用語集**: よく話す分野の言葉を「、」か改行で区切って並べます。整形のAIに毎回伝えるほか、画面に出ている言葉は聞き取りのヒントになります。初期値は書き方の見本なので、自分の言葉に書き換えてください。

## プライバシー

- 録音した音声と認識した文章は、保存しません（直前の結果をメモリに持つだけで、アプリを終了すると消えます）。
- 声がPCの外に出るのは、認識の方式を「クラウド（Groq）」にしたときだけです。
- 文章がPCの外に出るのは、整形・作文に外部のAI（OpenAI / Anthropic）を選んだときだけです。
- 診断タブの情報（処理時間など）にも、音声や文章は含みません。

## 困ったとき

- **何も入力されない**: タスクトレイのアイコンから設定画面を開き、表示が「利用可能」になっているか確かめてください。
- **遅い・録音が途切れる**: メモリ不足のことが多いです。大きなアプリ（ブラウザーのタブ、ChatGPTのアプリなど）を閉じてください。診断タブでメモリの状態を確かめられます。
- **F8が効かない**: 他のアプリが同じキーを使っている可能性があります。設定でショートカットを変えてください。

## アンインストール

Windowsの「設定」→「アプリ」→「インストールされているアプリ」から VoiceWeave をアンインストールします。認識モデルと設定は `%LOCALAPPDATA%\local.voiceweave.app` と `%APPDATA%\local.voiceweave.app` に残るので、不要なら削除してください。
